# Родблок

Менеджер родового отделения в духе Theme Hospital. Сутки дежурства с 08:00 до 08:00, ты — заведующий.

**Играть:** https://toporviking1-creator.github.io/Funnydeliveryunit/

## Что в игре

- **Отделение:** 19 боксов по зонам акушерок, распред на 2 места, доп палата на 6, две операционные, операционная в приёмном (до неё 5 минут на лифте), ОРИТН, ординаторская.
- **Смена:** 3 акушера-гинеколога, 3 анестезиолога, 2 неонатолога, 2 неонатолога-реаниматолога, 5 акушерок, клининг и зав.
- **Кнопки вызова в каждом боксе:** зелёная — акушер, жёлтая — неонатолог, красная — экстренный вызов. Мигает — никто не идёт, горит — врач в пути.
- **Клининг:** вызывается кнопкой на посту. Грязный бокс не занять, ВБИ растёт, учащаются хориоамниониты.
- **Решения зава с разбором:** сортировка в распреде, КТГ с мини-лентой, брадикардия (обратимая причина или острое событие), ПРК по 4Т, дистоция плечиков, эклампсия, лихорадка в родах.
- **Боссы-наплывы:** «ОПБ спускает всех», «Переводы из области», «Вечерний вал скорых», финальная «Ночь полнолуния».
- **События:** проверка ДЗМ, блогерша с планом родов на 12 листах, роды в лифте, отслойка с улицы, свекровь, доула, сломанная кофемашина.
- **Сдача смены:** звёзды, доля КС, КАС, асфиксии, боссы и разбор ошибок.

## Управление

- Тап по боксу — пациентка, задачи и кого послать.
- Тап по сотруднику — куда отправить, снять с задачи или уложить спать.
- Тап по посту — вызвать клининг.
- Лоток внизу — решения, которые ждут зава.
- Пробел — пауза, клавиши 1, 2, 4 — скорость.

## Как устроено

- `index.html` — готовая игра одним файлом, её раздаёт GitHub Pages.
- `src/` — исходники: данные (`data.js`), движок (`engine1–4.js`), интерфейс (`ui1–3.js`), стили и разметка.
- `build.sh` — собирает `src/` в `index.html`.
- `tools/sim.js` — прогон суток ботом для проверки баланса: `node tools/sim.js good 10`.

Игра учебно-развлекательная: клинические развилки упрощены и не заменяют клинические рекомендации.
